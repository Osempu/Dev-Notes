Most starter customization happens in `theme.config.json`.

```json title="theme.config.json"
{
  "$schema": "https://astro-theme-lotus.prosefly.dev/schema.json",
  "name": "Lotus Starter",
  "description": "Documentation built with Astro Theme Lotus.",
  "search": {
    "provider": "local"
  }
}
```

## Navigation

Use `siteNav` for top-level links and `docsNav` for docs navigation.

```json title="theme.config.json" showLineNumbers=true
{
  "docsBase": "/",
  "siteNav": [{ "label": "Docs", "href": "/overview/" }],
  "docsNav": [
    {
      "label": "Start Here",
      "items": ["overview", "installation", "customization"]
    }
  ]
}
```

```csharp title="mycode.cs" showLineNumbers=true
    static void Main()
    {
        Console.Write("Enter two integers: ");
        string? input = Console.ReadLine();

        // Validate input
        if (string.IsNullOrWhiteSpace(input))
        {
            Console.WriteLine("No input provided.");
            return;
        }

        string[] parts = input.Split(' ', StringSplitOptions.RemoveEmptyEntries);

        if (parts.Length != 2 ||
            !int.TryParse(parts[0], out int num1) ||
            !int.TryParse(parts[1], out int num2))
        {
            Console.WriteLine("Invalid input. Please enter two integers separated by space.");
            return;
        }

        int result = LCM(num1, num2);
        Console.WriteLine($"LCM of {num1} and {num2} is: {result}");
    }
```

## Content

Add pages under `src/content/docs`. This starter sets `docsBase: '/'`, so
`src/content/docs/guides/deploy.mdx` renders at `/guides/deploy/`.
